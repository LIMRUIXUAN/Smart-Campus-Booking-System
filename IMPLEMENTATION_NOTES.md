# Implementation Notes

The UI must follow DESIGN.md and the Stitch design references.

Main priority:
1. Keep layout close to Stitch design
2. Use React + Vite + Tailwind CSS
3. Use reusable components
4. Keep desktop and mobile responsive
5. Do not redesign the app from scratch unless required
6. Use mock data first if backend is not ready
7. Later connect to Spring Boot APIs
